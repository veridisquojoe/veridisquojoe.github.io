From my time in the UVA School of Data Science. In this project I show how data science could have augmented the provision of life-saving relief after the 2010 Haiti earthquake, compare traditional classification techniques with machine learning methods for a color-based classification problem, iterate through a cost/benefit analysis where a tailored "F-score" balances precision and recall, wrangle and combine large datasets, output a color palette based on RGB data, and map lat-long data using the mapview package.
